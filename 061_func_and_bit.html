def：同じことを二度書かない

複雑な計算や何度も使う処理を、一つの「名前」にひとまとめにします。

  • コードが短く読みやすくなる
  • 修正が必要なとき、1箇所直せば全て直る
def blink(times):
    for i in range(times):
        led.on()
        sleep(0.2)
        led.off()

# 登録した名前を呼ぶだけ
blink(5)

応用：センサー値の変換関数

マイコンが読み取る「0〜65535」のデジタル値を、意味のある「温度(℃)」に直す流れです。

  • 生のADC値を読み取る
  • 電圧(V)に換算する
  • 電圧を温度に変換する
def read_temp(pin_val):
    # 1. ADC値を電圧に
    voltage = (pin_val / 65535) * 3.3
    
    # 2. 電圧を温度に変換
    temp = voltage * 100
    
    return round(temp, 1)

t = read_temp(adc.read_u16())

2の補数：車のメーターの逆回転

コンピュータには「マイナス記号」が存在しません。
そこで、0から逆に回ってカンストする現象を利用します。

  • 桁数（ビット数）には上限がある。
  • 0 から 1 を引くと最大値に戻る。
  • その「最大値」を -1 として扱う！
